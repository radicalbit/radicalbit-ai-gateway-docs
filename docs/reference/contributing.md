# Contributing

Thank you for your interest in contributing to the Radicalbit AI Gateway.

## Reporting Issues

Create an issue on our GitHub repository for:

- **Bug reports** — include steps to reproduce, expected behaviour, and actual behaviour
- **Feature requests** — describe the use case and what you'd like to see
- **Documentation issues** — typos, unclear explanations, or missing information

## Pull Requests

We welcome contributions. Open a pull request on GitHub with a clear description of what you changed and why.

For significant changes, we recommend opening an issue first to discuss the approach before investing time in implementation.
