# Enterprise

The Enterprise edition includes all open-source features of the Radicalbit AI Gateway, plus:

- **Access Control** — Role-based access control (ADMIN, BUILDER, AUDITOR) with Keycloak IDP integration for user/group sync and OIDC Single Sign-On for the admin dashboard. See [Access Control](../access-control/index.md).

- **Secrets Management** — Pluggable secret providers to keep API keys and credentials out of config files. Supports AWS Secrets Manager, Google Cloud Secret Manager, Azure Key Vault, and HashiCorp Vault. See [Secrets Management](../deployment/secrets-management/index.md).
